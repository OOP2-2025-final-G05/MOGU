# MOGUMOGUレビュー

## アプリ説明
MOGUMOGUレビューは、飲食店🍽️をユーザー👤同士が自由🗽に登録し、レビュー⭐️を投稿・閲覧できるアプリケーションです。

## アピールポイント
1. 簡単操作で誰でも利用できる！
2. 自由にお店を登録できる！
3. 匿名であるため、正直なレビューを投稿できる！
4. お店が新しく登録された順に表示されるため、最近の流行りが分かりやすい！

## アプリ画面
 
- お店登録画面
> - 「トップ画面」から「お店登録」を押すと表示されます。
> - 誰でも好きなお店を自由に登録できます。
> - 記入例が枠の中に表示されているため、どのように記入すればいいか分かりやすいです。
![](restaurant_registration_image.png)
 
- お店一覧画面(GIFあり)
> - 「トップ画面」から「お店一覧」を押すと表示されます。
> - ユーザーが登録したお店が一覧表示されます。
> - 「評価◯以上・住所」で絞り込むことができます。
![list demo](list.gif)
 
- お店詳細画面(GIFあり)
> - 「お店一覧」から「お店名」を押すと表示されます。
> - お店の詳細情報と、ユーザーのレビューが表示されます。
> - 評価の分布がわかりやすく表示されます。
> - スクロールして複数のレビューを閲覧できます。
![details demo](details.gif)
 
- レビュー画面(GIFあり)
> - 「お店一覧」から「レビュー」を押すと表示されます。
> - 直感的な操作で星の評価をすることができます
> - 好きなようにコメントを記入できます。
![review star demo](review_star.gif)

- スマートフォンの画面
> - スマートフォンでも動作します。
> - 同じネットワーク内であれば、サーバーに入ることができます。
![](smartphone_screen.png)

## 動作条件

```bash
python 3.13 or higher

# python lib
Flask==3.0.3
peewee==3.17.7
```

## 使い方

bashで以下のコマンドを入力する
```
$ python app.py
```
入力したあと、エラーがないか確認して
```
http://localhost:5001
```
にアクセスする

同じネットワーク内の誰かがサーバーを開いていれば
```
http://サーバー開設者のIPアドレス:5001
```
でアクセスできる
