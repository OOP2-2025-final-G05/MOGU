# MOGUMOGUレビュー

## トップページ
> 「お店登録・お店一覧・レビュー」ボタンが表示。ボタンをクリックすると、それぞれのページに遷移する。
![](top_image.jpeg)
 
## お店登録画面
> 「お店名、お店住所、ジャンル(選択)、価格帯(選択)下限上限、営業時間(選択)」を登録。「登録」ボタンを押して登録。
![](restaurant_registration_image.jpeg)
 
## お店一覧画面
> 「お店名、お店住所、ジャンル、価格帯(下限上限)、評価(平均)、編集ボタン」を表示。お店の行を押したら「お店詳細」に遷移。編集ボタンを押すと「編集」画面に遷移。
![](restaurant_list_image.jpeg)
 
## お店詳細画面
> 「お店名、お店住所、ジャンル、価格帯(下限上限)、営業時間、コメント、評価(平均、レビューごとの評価)、それぞれの年齢、ぞれぞれの性別」を表示。スクロールして複数のレビューを閲覧できる。
![](restaurant_details_image.jpeg)
 
## 編集画面
> お店の登録情報を編集。見た目は「お店登録」とほぼ同じ。開いた時にすでに欄は埋まっている状態。
![](restaurant_edit_image.jpeg)
 
## レビュー画面
> 「お店名(選択)、評価(選択)、年齢、性別(選択)、コメント」を登録。
![](review_image.jpeg)
